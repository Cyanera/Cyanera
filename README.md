# عهد — صفحة شخصية

صفحة شخصية بأسلوب Portfolio تجمع الأدوات الرقمية التي صُنعت للفائدة بمعونة الذكاء الاصطناعي.
صفحة واحدة ساكنة (HTML + CSS + قليل من JavaScript)، بلا أدوات بناء ولا اعتماديات.

- **الاتجاه:** من اليمين إلى اليسار، بلغة عربية.
- **الخط:** خط ثمانية بأوزانه الخمسة، مستضافًا داخل المستودع.
- **اللون الأساسي:** الأزرق الصريح `#0000FF`، مع لمسة رملية `#F7F1E6` وذهبية `#FFCB6B`.
- **التجاوب:** يعمل من شاشات الجوال الصغيرة حتى الشاشات العريضة.
- **الاستقلال:** لا طلبات إلى أي خدمة خارجية؛ كل ما تحتاجه الصفحة هنا.

## الملفات

| الملف         | الغرض                                            |
| ------------- | ------------------------------------------------ |
| `index.html`  | محتوى الصفحة: التعريف، بطاقات الأدوات، الخاتمة.   |
| `styles.css`  | التصميم كاملًا، مقسّمًا إلى أقسام معنونة بالعربية. |
| `main.js`     | حركة الظهور اللطيفة عند التمرير (تحسين اختياري). |
| `fonts/`      | ملفات خط ثمانية بأوزانها الخمسة.                 |
| `favicon.svg` | أيقونة الموقع.                                   |

## إضافة أداة جديدة

قسم الأدوات مبنيّ على شبكة تتكيّف مع أي عدد من البطاقات، فالإضافة لا تحتاج أكثر من نسخ بطاقة:

1. افتحي `index.html` وابحثي عن التعليق `▸ الصق البطاقة الجديدة هنا`.
2. انسخي إحدى البطاقتين الموجودتين كاملةً — من `<li class="reveal">` حتى `</li>` — والصقيها مكان التعليق.
3. عدّلي في النسخة الجديدة:
   - `card__num`: الرقم التالي بالأرقام العربية (`٠٣`، `٠٤`، …).
   - `card__title`: اسم الأداة.
   - `card__tag`: وسمٌ قصير يصفها (كلمتان على الأكثر).
   - `card__desc`: وصف الأداة.
   - `href` في الزر: رابط الموقع.
   - `card__domain`: اسم النطاق الظاهر أسفل الزر.

الترتيب والتجاوب والحركة تُضبط تلقائيًا، فلا حاجة لتعديل `styles.css` أو `main.js`.

## المعاينة محليًا

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```

## النشر على GitHub Pages

من إعدادات المستودع: **Settings ← Pages ← Source: Deploy from a branch**، ثم اختاري الفرع ومجلد الجذر `/`.

## الخط

الموقع يستعمل **خط ثمانية** (عائلة ثمانية سيريف تكست) بأوزانه الخمسة، وملفاته
داخل مجلد [`fonts/`](fonts/README.md) تُقدَّم من الموقع نفسه — فلا تطلب الصفحة
أي ملف من خدمة خارجية، ولا تعتمد على شبكة توصيل أو خطوط Google.

الخط من تصميم وملكية [ثمانية](https://thmanyah.com)، وتفاصيل ترخيصه على
[font.thmanyah.com/licenses](https://font.thmanyah.com/licenses).
