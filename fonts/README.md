# خطوط الموقع

هنا ملفات **خط ثمانية** (عائلة ثمانية سيريف تكست) التي يستعملها الموقع،
بصيغة `woff2` وبخمسة أوزان:

| الملف                             | الوزن       |
| --------------------------------- | ----------- |
| `thmanyah-serif-text-Light`       | خفيف — ٣٠٠  |
| `thmanyah-serif-text-Regular`     | عادي — ٤٠٠  |
| `thmanyah-serif-text-Medium`      | متوسط — ٥٠٠ |
| `thmanyah-serif-text-Bold`        | عريض — ٧٠٠  |
| `thmanyah-serif-text-Black`       | أسود — ٩٠٠  |

قواعد `@font-face` مكتوبة في أعلى `styles.css` تحت اسم العائلة `Thmanyah`.
والصفحة اليوم تستعمل: ٤٠٠ للنصوص، و٥٠٠ للأزرار والوسوم، و٧٠٠ للعناوين،
و٩٠٠ للعنوان الأكبر. ولا يحمّل المتصفح إلا الأوزان الظاهرة فعلًا في الصفحة.

## لتغيير وزنٍ في مكانٍ ما

كل الأوزان الخمسة مُعرَّفة وجاهزة، فيكفي تعديل `font-weight` في القاعدة المعنيّة
داخل `styles.css` — مثلًا `900` بدل `700` لعناوين البطاقات.
