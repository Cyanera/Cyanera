# مجلد خط ثمانية

خط ثمانية هو الخط الأساسي لهذه الصفحة، وملفاته **غير مرفوعة** في المستودع
احترامًا لترخيص [ثمانية](https://thmanyah.com)، فالخط من تصميمها وملكيتها.

## الخطوات

1. نزّلي الخط من موقعه الرسمي: <https://font.thmanyah.com>
2. أعيدي تسمية الملفات إلى الأسماء التالية بالضبط، وضعيها في هذا المجلد:

   | الملف                                | الوزن           |
   | ------------------------------------ | --------------- |
   | `Thmanyah-Sans-Regular`              | عادي (400)      |
   | `Thmanyah-Sans-Medium`               | متوسط (500)     |
   | `Thmanyah-Sans-Bold`                 | عريض (700)      |
   | `Thmanyah-Serif-Display-Regular`     | عناوين — عادي   |
   | `Thmanyah-Serif-Display-Bold`        | عناوين — عريض   |

3. الامتداد `.woff2` هو الأفضل للويب (أخفّ وأسرع)، و`.otf` يعمل كذلك؛
   وقد كُتبت قواعد `@font-face` في `styles.css` لتقبل الاثنين معًا،
   فلا حاجة لأي تعديل بعد وضع الملفات.

> **تحويل من `.otf` إلى `.woff2`:** إن نزّلتِ ملفات `.otf` وأردتِ تخفيفها،
> استخدمي أي محوّل ويب موثوق، أو الأمر:
> `pip install fonttools brotli && fonttools ttLib.woff2 compress Thmanyah-Sans-Regular.otf`

## قبل وضع الملفات

الصفحة تعمل وتبدو متّسقة دون أي تدخّل: تتراجع تلقائيًا إلى خط
**IBM Plex Sans Arabic** — وهو خط عربي حديث مفتوح المصدر قريب الروح من خط ثمانية —
ثم إلى خطوط النظام العربية إن تعذّر ذلك أيضًا.
